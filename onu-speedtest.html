Sandi diperiksa oleh nginx, bukan oleh halaman ini. Pasang sekali di server:

apt install -y apache2-utils
htpasswd -c /etc/nginx/.htpasswd farabi

Lalu di blok location /nbi/:

auth_basic "MAHAMARTA";
auth_basic_user_file /etc/nginx/.htpasswd;

Menambah operator lain: htpasswd /etc/nginx/.htpasswd namabaru — tanpa -c, kalau pakai -c file lama ditimpa.

Logo: taruh mahamarta.png atau mahamarta.svg di folder yang sama dengan halaman ini.

Untuk unggah, server harus menerima PUT lewat modul DAV:

location /upload/ {
    alias /var/www/upload/;
    dav_methods PUT DELETE;
    client_max_body_size 0;
    client_body_temp_path /var/tmp/nginx_up;
    create_full_put_path on;
    dav_access user:rw group:rw all:r;
}
